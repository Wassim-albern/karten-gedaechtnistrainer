# Karten-Gedächtnistrainer

Ein responsiver React-Kartentrainer für vier Spieler.

## Lokal starten

```bash
npm install
npm run dev
```

## GitHub Pages

1. Repository mit dem Namen `karten-gedaechtnistrainer` erstellen.
2. Alle Projektdateien hochladen.
3. Unter **Settings > Pages > Source** die Option **GitHub Actions** wählen.
4. Nach dem erfolgreichen Workflow ist die Seite online.

Falls das Repository anders heißt, `base` in `vite.config.js` anpassen.
